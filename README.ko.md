# ShellAnchor

[English](README.md) | **한국어**

자주 쓰는 기능만 골라 만든 브라우저용 SSH 클라이언트입니다.
이 PC에서 도는 작은 중계 서버(Python)가 브라우저와 SSH 서버를 연결합니다.

```
브라우저(xterm.js) ──WSS── server.py ──SSH── [점프 호스트 ──] 대상 서버
                            ├─ SFTP / 세션 로그 / 원격 모니터링
                            ├─ SSH 터널 (로컬 포워딩, SOCKS5)
                            ├─ 로컬 터미널 (PowerShell / cmd / WSL)
                            └─ RDP → Windows 원격 데스크톱(mstsc) 실행
```

> **지원 환경**: Windows 10/11 + Python 3.11 이상(3.12에서 테스트) + Chrome/Edge.
> 로컬 터미널·RDP·인증서 자동 신뢰 등록은 Windows 전용입니다. 다른 OS에서는 시험하지 않았습니다.

## 설치

```bat
git clone https://github.com/<owner>/shellanchor.git
cd shellanchor
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

또는 **`실행(콘솔).bat`** 더블클릭 — `.venv`가 없으면 만들고 패키지를 설치한 뒤 바로 실행합니다.

## 실행

```bat
.venv\Scripts\python server.py --open --trust
```

→ 크롬 앱 창으로 `https://127.0.0.1:8022/`가 열립니다.
처음 한 번 Windows "인증서 설치" 경고 → **예** (이 PC 전용 로컬 CA. 이후 브라우저 경고 없음).

**콘솔 창 없이 실행하기** — 바로가기(.lnk)를 하나 만들어 두면 편합니다.

| 항목 | 값 |
| --- | --- |
| 대상 | `<설치 폴더>\.venv\Scripts\pythonw.exe server.py --open --trust --auto-exit` |
| 시작 위치 | `<설치 폴더>` |

- 이미 실행 중이면 서버를 또 띄우지 않고 창만 다시 엽니다
- **끄기**: ⚙설정 → **서버 종료**. `--auto-exit`로 띄웠다면 브라우저 창을 모두 닫고 1분 뒤 자동 종료 (SSH 터널이 실행 중이면 유지)
- 창 없이 실행할 때 오류는 메시지 창으로 알려 주고, 자세한 기록은 `data\server.log`

```bat
python server.py --host 0.0.0.0   :: 다른 PC에서도 접속 (토큰 필수, 로컬 터미널·RDP 실행은 꺼짐)
python server.py --port 9022      :: 다른 포트
python server.py --no-tls         :: HTTPS 끄기 (평문 HTTP, 권장하지 않음)
```

## 기능

### 상단 바 편집

필요한 기능만 상단 바에 올려 두세요. 오른쪽 끝 **⋯** 또는 상단 바 **우클릭 → 상단 바 편집…**

- 체크로 보이기/숨기기, 끌어서(또는 Alt+↑↓) 순서 변경. 바꾸는 즉시 미리 보기, 취소하면 원래대로
- **빈 공간** 뒤의 항목은 오른쪽 끝에 붙음. **구분선**도 원하는 위치에
- 기본 버튼 외에 올릴 수 있는 기능: SFTP 패널, 사이드바 접기/펴기, 현재 탭 복제·재접속·닫기, 새 세션 폴더, MobaXterm 세션 가져오기
- **아이콘만 표시**로 상단 바를 좁게 (버튼 이름은 마우스를 올리면 보임)
- 버튼 우클릭 → 그 버튼만 바로 숨기기. 설정은 브라우저별로 저장

### 세션 관리

- **세션 폴더 트리**: 폴더/하위 폴더, 끌어다 놓아 이동, 검색, 더블클릭 접속, 우클릭 메뉴(편집·복제·삭제)
- 세션 종류: **SSH / RDP / 로컬 터미널**
- **MobaXterm 세션 가져오기** (트리 위 ⤓): `MobaXterm.ini` 또는 내보낸 `.mxtsessions` 선택
  → SSH·RDP 세션과 폴더 구조를 그대로 가져옴 (비밀번호는 가져오지 않음)
- 비밀번호는 **저장하지 않음**. 접속할 때 묻고, 창을 닫을 때까지만 기억(재접속·탭 복제 때 다시 안 물음)
- 개인키는 파일 경로로 지정 (`찾기…` 버튼). 키 암호가 걸려 있으면 접속할 때 물어봄. PuTTY `.ppk`는 OpenSSH 형식으로 변환 필요
- **자동 재접속**: 네트워크가 끊기면 3·5·10·20·30초 간격으로 재시도. 직접 `exit`한 경우는 재접속 안 함. 끊긴 탭에서 `R` = 재접속, `Enter` = 탭 닫기
- **세션 로그**: 세션 편집에서 "세션 로그 저장" → `logs/<세션이름>/<날짜_시각>_<host>.log` (색상코드 제거된 텍스트). 툴바 ≡로그 = 폴더 열기

### 터미널

- **화면 분할**(툴바 ▦): 한 화면 / 좌우 / 상하 / 4분할. 탭을 누르면 선택된 칸에 표시, 새 접속은 빈 칸부터 채움
- **키워드 하이라이트**: error·fail·denied(빨강), warning·timeout(노랑), ok·success(초록), IP 주소(파랑). 설정에서 정규식·색 편집.
  출력 자체는 바꾸지 않고 화면에만 색을 덧칠 (로그·복사 내용은 원본 그대로). vim·top 같은 전체화면 프로그램에서는 동작 안 함
- 인코딩 UTF-8 / EUC-KR, 점프 호스트 경유
- 복사 = 드래그, 붙여넣기 = 우클릭 (Ctrl+Shift+C/V도 가능)

### SFTP (왼쪽 사이드바, SSH 접속하면 자동으로 열림)

- **터미널 폴더 따라가기**: 터미널에서 `cd` 하면 SFTP도 그 폴더로 (Linux 서버). `cd↵` = 반대로 터미널을 SFTP 폴더로
- **원격 파일 바로 편집**: 파일 더블클릭 → 편집기, Ctrl+S 저장. 편집 중 서버에서 파일이 바뀌면 덮어쓰기 전에 경고. EUC-KR·CRLF 유지
- **폴더 통째로 업로드/다운로드**: 폴더를 끌어다 놓거나 `⬆ 폴더`. 다운로드는 저장할 폴더를 고르면 구조 그대로 저장
- **권한/소유자 변경**: 우클릭 → 권한 / 소유자 (체크박스·8진수, 하위까지 적용 가능. 소유자 변경은 root 권한 필요)
- 여러 개 선택(Ctrl/Shift+클릭), Del 삭제(폴더는 내용까지), F2 이름 바꾸기, 경로 복사

### 그 외

- **테마**: 화면 테마(라이트·다크·Windows 설정 따라가기)와 터미널 색(밝게, Solarized Light/Dark, 클래식 다크, Windows Terminal, Dracula 등)을 ⚙설정에서 따로 고름. 고르면 바로 미리보기. 브라우저별로 기억. 밝은 터미널에서는 키워드 하이라이트 색을 자동으로 진하게 보정
- **SSH 터널** (사이드바 "터널"): 로컬 포워딩(내 127.0.0.1:포트 → SSH 서버 경유 → 원격 서비스), 동적 SOCKS5.
  ▶/■ 로 시작·중지. 브라우저 탭을 닫아도 서버가 켜져 있으면 유지되고, 끊기면 5초마다 자동 재연결
- **원격 모니터링 바** (아래): 현재 탭 서버의 CPU·메모리·디스크(/)·네트워크·Load·가동 시간 (Linux, 3초마다)
- **로컬 터미널** (툴바 ▣): PowerShell / cmd / (설치돼 있으면) WSL
- **RDP**: RDP 세션 더블클릭 → Windows 원격 데스크톱 실행. "SSH 게이트웨이 경유"를 고르면 그 SSH 세션을 통해 터널을 만들고 연결
  (원격 데스크톱 창을 닫으면 터널도 자동 정리). 비밀번호는 원격 데스크톱 창에서 입력

## 보안

- 기본 127.0.0.1 바인딩. `--host 0.0.0.0`이면 토큰 필수 + 로컬 터미널·RDP 실행·파일 선택창은 꺼짐(원격에서 이 PC 조작 방지)
- HTTPS: 로컬 CA에 Name Constraints(localhost·사설 IP만) → `certs/ca.key`가 새도 외부 사이트 위조 불가
- WebSocket Origin 검사(CSWSH 차단), 호스트 키 TOFU(`data/known_hosts`, 바뀌면 접속 거부)
- 비밀번호·키 암호는 디스크에 저장하지 않음. 실행 중인 터널만 재연결을 위해 서버 메모리에 보관
- 터널은 항상 127.0.0.1에만 열림
- `certs/`, `data/`, `logs/`는 PC마다 생성되는 개인 데이터라 저장소에 포함되지 않습니다(`.gitignore`)

## 파일

| 파일                  | 역할                                                                                       |
| --------------------- | ------------------------------------------------------------------------------------------ |
| `server.py`           | HTTPS·WebSocket 라우팅, 실행 옵션                                                          |
| `term.py`             | SSH 터미널 중계, 세션 로그, 모니터링, 터미널 폴더 추적                                     |
| `sftp.py`             | SFTP (목록·전송·편집·권한·폴더 작업)                                                       |
| `sshconn.py`          | SSH 접속·점프·호스트 키·키 파일                                                            |
| `tunnels.py`          | SSH 터널 (로컬 포워딩·SOCKS5, 자동 재연결)                                                 |
| `localterm.py`        | 로컬 터미널 (ConPTY)                                                                       |
| `api.py`              | 세션 트리·설정 저장, 터널 제어, RDP 실행                                                   |
| `tls.py`, `common.py` | 인증서, 공통 설정                                                                          |
| `static/`             | 화면 (core·app·tree·sftp·tunnels·highlight·toolbar .js)                                          |
| `data/`               | `sessions.json`(세션·폴더·터널), `settings.json`, `known_hosts`, `rdp/` — 백업은 이 폴더만 |
| `logs/`               | 세션 로그 (설정에서 위치 변경 가능)                                                        |
